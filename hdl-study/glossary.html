五章出現的中英術語彙整。每個詞條都附一句話定義與「出現於」連結，可直接跳到講到它的小節。 技術名詞一律中英並列；定義是為了快速回想而寫的摘要，詳細說明請看對應章節。

顯示 63 / 63 個詞條

  • 硬體描述語言hardware description language, HDL

    用文字描述硬體的結構與行為的語言，同一份描述既可用來模擬驗證，也可用來合成成實際電路。

    出現於：01 §1.2 為什麼要學硬體描述語言01 §1.3 廣義的 HDL

  • 網表netlist

    列出元件與其接線關係的文字檔；投影片的用法是閘級以上的文字描述叫 HDL，電晶體級的連接描述叫 NETLIST。

    出現於：01 §1.3 廣義的 HDL01 §1.8 結構模型

  • 模組module

    Verilog 的基本設計單位，用 module / endmodule 包住埠宣告與內容，可以被其他模組實體化。

    出現於：01 §1.12 Verilog 檔案與模組的外觀03 §3.6 模組與實體

  • 實體instance

    某個模組在另一個模組內實際擺放的一份複本；實體化造出設計階層，一個模組可以被實體化多次。

    出現於：03 §3.6 模組與實體02 §2.2 階層、樹與嵌套區塊

  • 埠port

    模組對外的接腳，方向分為 input、output、inout；實體化時以位置或名稱與外部接線對應。

    出現於：03 §3.7 埠與接線的對應01 §1.12 Verilog 檔案與模組的外觀

  • 接線net / wire

    連接元件輸出與輸入的導線型別，值完全由驅動源決定，只能用連續指定驅動，不能在程序區塊內被指定。

    出現於：03 §3.4 資料型別與常數03 §3.17 左值與 reg

  • 暫存器register

    保存一組位元的儲存元件。注意 Verilog 的 reg 只是「可被程序指定的變數」，不保證合成出實體暫存器。

    出現於：01 §1.10 暫存器層的功能模型 RTL03 §3.17 左值與 reg

  • 正反器flip-flop, FF

    邊緣觸發的一位元儲存元件，是循序電路保存狀態的單位；Huffman 模型中 M 個正反器最多表示 2M 個狀態。

    出現於：03 §3.25 範例：正反器01 §1.9 邏輯層的功能模型

  • 閂鎖器latch

    準位觸發的一位元儲存元件：控制訊號為真的期間輸出跟著輸入變化，為假時保持住值。

    出現於：03 §3.25 範例：正反器03 §3.18 Verilog 的八種 Block

  • 多工器multiplexer, MUX

    用選擇訊號從多個輸入中挑一個送到輸出的組合元件；ASM 圖裡的判斷分支就對應到多工器類的選擇電路。

    出現於：03 §3.11 RTL 由程式庫合成04 §4.22 ASM 元件對應到硬體

  • 解多工器demultiplexer

    把一個輸入依選擇訊號送到多個輸出之一的組合元件；ASM 圖的判斷菱形在硬體上就是解多工器的角色。

    出現於：04 §4.18 流程圖對應到 ASM 圖的三條規則04 §4.22 ASM 元件對應到硬體

  • 組合邏輯combinational logic

    輸出只由當前輸入決定、不含記憶的邏輯；可用真值表、布林式或卡諾圖完整描述。

    出現於：01 §1.9 邏輯層的功能模型03 §3.14 內容順序與時序、可合成的範圍

  • 循序邏輯sequential logic

    輸出同時取決於輸入與內部狀態的邏輯；由組合邏輯加上儲存元件組成，可用狀態圖或狀態表描述。

    出現於：04 §4.4 循序電路的四種看法05 §5.1 Huffman 模型

  • 時脈clock

    驅動同步電路前進的週期性訊號；Verilog 以 posedge / negedge 指定在哪個邊緣觸發。

    出現於：03 §3.25 範例：正反器05 §5.1 Huffman 模型

  • 同步與非同步synchronous / asynchronous

    同步是所有狀態改變都發生在時脈邊緣；非同步則不等時脈，訊號一到就作用（例如非同步重設）。

    出現於：03 §3.26 範例：計數器05 §5.15 計數器型狀態機

  • 抽象層級abstraction level

    描述設計時的粗細程度，由高到低例如系統、演算法、暫存器、邏輯、開關、電路層；在 Y 圖上以同心圈表示，越外圈越抽象。

    出現於：01 §1.6 層級與觀點、Y 圖02 §2.9 Y 圖與理想 EDA 流程

  • 觀點view

    看同一個設計的三種角度：行為、結構、實體；在 Y 圖上是三條軸。

    出現於：01 §1.6 層級與觀點、Y 圖02 §2.9 Y 圖與理想 EDA 流程

  • Y 圖Y-chart

    Gajski 提出的圖：三條軸是行為／結構／實體三種觀點，同心圈是抽象層級，EDA 工作則是在軸與圈之間移動的弧線。

    出現於：01 §1.6 層級與觀點、Y 圖02 §2.9 Y 圖與理想 EDA 流程

  • 行為觀點behavioral view

    只描述「做什麼」：輸入到輸出的功能與時序關係，不指定用哪些元件實現。

    出現於：01 §1.6 層級與觀點、Y 圖03 §3.13 什麼是「行為」

  • 結構觀點structural view

    描述「由什麼組成」：有哪些元件實體、它們之間怎麼接線，遞迴下去直到視為已知的基本元件。

    出現於：01 §1.8 結構模型02 §2.9 Y 圖與理想 EDA 流程

  • 實體觀點physical view

    描述「長什麼樣、擺在哪」：幾何形狀、面積、位置與佈局繞線的結果。

    出現於：01 §1.6 層級與觀點、Y 圖02 §2.7 由下而上合成八步

  • 暫存器轉移層register transfer level, RTL

    以「在哪個時脈邊緣、把哪個運算結果搬進哪個暫存器」來描述設計的層級，是目前合成流程的主要輸入。

    出現於：01 §1.10 暫存器層的功能模型 RTL03 §3.11 RTL 由程式庫合成

  • 閘級gate level

    以邏輯閘與接線描述電路的層級；Verilog 直接提供 and、or、not 等基本閘。

    出現於：01 §1.8 結構模型03 §3.10 閘級設計範例與突波消除

  • 開關級switch level

    以電晶體開關（nmos、pmos、tranif1 等）描述電路的層級，是 Verilog 四種模型中最接近實作的一種。

    出現於：03 §3.9 Verilog 的四種模型03 §3.8 數位 IC 設計自動化的四個層次

  • 行為模型behavioral model

    用程序敘述（always、initial、迴圈、條件）直接寫出功能的模型，抽象度最高，不保證每一行都可合成。

    出現於：03 §3.13 什麼是「行為」04 §4.2 RTL 還是行為模型？

  • 合成synthesis

    把較抽象的描述自動轉成較具體的結構，例如把 RTL 轉成程式庫裡的閘與正反器；在 Y 圖上是由行為軸走向結構軸的弧。

    出現於：02 §2.9 Y 圖與理想 EDA 流程03 §3.11 RTL 由程式庫合成

  • 模擬simulation

    在電腦上依事件推進時間、算出電路對一組輸入的反應，用來驗證設計是否符合預期。

    出現於：01 §1.4 主要 HDL 的定位與發展史03 §3.16 電路時間與 CPU 時間、時間輪

  • 測試平台testbench / testfixture

    只為模擬而寫、不必可合成的外圍模組：產生輸入訊號、實體化待測設計、觀察並檢查輸出。

    出現於：02 §2.3 測試平台 Testbench 的概念03 §3.20 命令列與監看輸出

  • 敏感度列表sensitivity list

    always @(…) 括號裡的事件清單，列出哪些訊號變化（或哪個時脈邊緣）會觸發這個區塊重新執行。

    出現於：03 §3.15 Verilog 的事件03 §3.18 Verilog 的八種 Block

  • 阻塞指定blocking assignment

    寫成 = 的程序指定：立刻算出並立刻寫入，後面的敘述會看到新值，順序會影響結果。

    出現於：03 §3.23 阻塞與非阻塞的逐步比較03 §3.21 三種指定敘述

  • 非阻塞指定non-blocking assignment

    寫成 <= 的程序指定：先用舊值全部求值，到該時間點結束才全部寫入，所以同一個區塊內的敘述順序不影響結果。

    出現於：03 §3.23 阻塞與非阻塞的逐步比較03 §3.21 三種指定敘述

  • 連續指定continuous assignment

    assign 敘述：右式任一訊號變動就重算並持續驅動左邊的接線，相當於一塊永遠通電的組合邏輯。

    出現於：03 §3.21 三種指定敘述03 §3.10 閘級設計範例與突波消除

  • 事件驅動event-driven

    模擬器的運作方式：只在有訊號變動（事件）時才計算受影響的部分，而不是每個時間點都重算全電路。

    出現於：03 §3.15 Verilog 的事件03 §3.16 電路時間與 CPU 時間、時間輪

  • 時間輪time wheel

    模擬器用來排程未來事件的環狀佇列：每個時間槽掛著該時刻要處理的事件，處理完就轉到下一槽。

    出現於：03 §3.16 電路時間與 CPU 時間、時間輪

  • Huffman 模型Huffman model

    循序電路的標準結構：一塊組合邏輯加上回授的狀態儲存元件；M 個正反器最多給出 2M 個狀態。

    出現於：05 §5.1 Huffman 模型01 §1.9 邏輯層的功能模型

  • 現在狀態與下一狀態present state / next state, PS/NS

    狀態表的兩個欄位：PS 是目前存在正反器裡的狀態，NS 是在這組輸入下、下個時脈邊緣要進入的狀態。

    出現於：05 §5.5 轉移表、布林式與閘級實作01 §1.9 邏輯層的功能模型

  • 有限狀態機finite state machine, FSM

    狀態數目有限的循序機器，用狀態、轉移條件與輸出三者描述；是控制電路最常用的模型。

    出現於：05 §5.2 常見的有限狀態機01 §1.9 邏輯層的功能模型

  • Mealy 機Mealy machine

    輸出同時取決於現在狀態與當前輸入的狀態機；狀態圖上輸出標在轉移邊上。

    出現於：05 §5.3 Mealy 與 Moore 的分類05 §5.4 Mealy 範例：密碼鎖 1011

  • Moore 機Moore machine

    輸出只取決於現在狀態的狀態機；狀態圖上輸出標在狀態圈內。

    出現於：05 §5.3 Mealy 與 Moore 的分類05 §5.7 Moore 範例：Recent Ones

  • 演算法狀態機algorithmic state machine, ASM

    把演算法直接對應成硬體的設計法：虛擬碼 → 流程圖 → ASM 圖 → 定序器加資料路徑，共四個步驟。

    出現於：04 §4.15 演算法狀態機 (ASM) 與四步設計流程

  • ASM 圖ASM chart

    由流程圖轉換而來、每個狀態剛好佔一個時脈週期的圖；轉換時要處理寫後讀相依、合併狀態與插入虛擬狀態。

    出現於：04 §4.18 流程圖對應到 ASM 圖的三條規則04 §4.21 流程圖 → ASM 圖對照

  • 一熱碼定序器one-hot sequencer

    每個狀態配一個正反器、同時只有一個為 1 的控制器；ASM 圖的狀態方塊可以一對一直接對應過來。

    出現於：04 §4.23 對應到狀態定序器04 §4.22 ASM 元件對應到硬體

  • 資料路徑datapath

    負責真正搬資料與做運算的部分（暫存器、加法器、移位器、多工器），由控制器發出的控制訊號指揮。

    出現於：04 §4.24 對應到 ALU / 資料路徑04 §4.25 完整設計：控制器 + 資料路徑

  • 關鍵路徑critical path

    組合邏輯中延遲最長的那條路徑，決定了電路能跑多快（最短的時脈週期）。

    出現於：04 §4.28 面積與時間的取捨

  • 扇出fanout

    一個閘的輸出同時接到幾個後級輸入；扇出數影響負載與延遲，也是結構性質之一。

    出現於：01 §1.8 結構模型

  • 主幹stem

    扇出到多個後級的那條輸出線（分枝的源頭）；投影片以 G3 同時餵給三個閘為例。

    出現於：01 §1.8 結構模型

  • 重匯合扇出reconvergent fanout

    從同一個主幹分出去的多條路徑，在後面又匯回同一個閘；這種結構會造成突波，也讓測試與分析變困難。

    出現於：01 §1.8 結構模型

  • 突波hazard / glitch

    輸入轉態瞬間因路徑延遲不同而出現的短暫錯誤脈衝；補上一致項（例如 B&C）可以消掉它。

    出現於：03 §3.10 閘級設計範例與突波消除

  • 二元決策圖BDD / ROBDD

    用一連串變數分枝表示布林函數的有向圖；化簡並固定變數順序後得到 ROBDD，可當成函數的標準表示法。

    出現於：01 §1.9 邏輯層的功能模型

  • 真值表truth table

    把所有輸入組合與對應輸出逐列列出的表；n 個輸入就有 2n 列，所以大電路無法用它描述。

    出現於：01 §1.9 邏輯層的功能模型02 §2.5 為什麼不能全部攤平

  • 基本立方體primitive cube

    把真值表壓縮後的表示法：用「不在意 (x)」合併多列，一列代表一群輸入組合。

    出現於：01 §1.9 邏輯層的功能模型

  • 卡諾圖Karnaugh map

    把真值表排成相鄰格只差一個位元的方格圖，用圈選相鄰格的方式化簡布林式、看出突波來源。

    出現於：03 §3.10 閘級設計範例與突波消除

  • 邊界掃描boundary scan

    在晶片每個接腳旁加一個掃描單元串成一條鏈，讓外部可以經由少數接腳觀察與驅動接腳狀態，用於板級測試。

    出現於：05 §5.9 JTAG 與邊界掃描05 §5.11 基本邊界掃描單元

  • JTAG / IEEE 1149.1JTAG / IEEE 1149.1

    邊界掃描的標準介面，額外用四支接腳 TMS、TCK、TDI、TDO 控制測試流程。

    出現於：05 §5.9 JTAG 與邊界掃描05 §5.10 晶片層的 1149.1 架構

  • TAP 控制器TAP controller, TAPC

    IEEE 1149.1 的 16 狀態控制器，只看 TMS 決定轉移；連續五個 1 一定回到 TestReset。

    出現於：05 §5.12 TAP 控制器：抽象狀態圖05 §5.13 TAP 控制器：完整 16 狀態

  • 環形計數器ring counter

    把移位暫存器的輸出接回輸入、只有一個 1 在環上繞的計數器；N 級給 N 個狀態，天然是一熱碼。

    出現於：05 §5.15 計數器型狀態機

  • Johnson 計數器Johnson counter

    回授時先反相的環形計數器（扭環計數器）；N 級可以得到 2N 個狀態。

    出現於：05 §5.15 計數器型狀態機

  • 線性反饋移位暫存器linear feedback shift register, LFSR

    以 XOR 回授的移位暫存器，能用很少的硬體產生近似隨機的長循環序列，常用於測試圖樣產生。

    出現於：05 §5.15 計數器型狀態機

  • 除頻器frequency divider

    用計數器把高頻時脈分出低頻訊號的電路，例如把開發板的 50 MHz 時脈降成人眼看得見的閃爍頻率。

    出現於：03 §3.27 Lab03 七段顯示器與除頻器05 §5.18 Lab05 按鈕計時器

  • 七段顯示器7-segment display

    由七段（常再加小數點）發光段組成的數字顯示元件，需要一個解碼器把二進位值轉成各段的亮暗。

    出現於：03 §3.27 Lab03 七段顯示器與除頻器

  • FPGA / SoPCFPGA / SoPC

    可現場燒寫邏輯的可程式元件；在它上面再放進處理器與周邊，就成為可程式晶片系統 (SoPC)。本課程用的 DE0 開發板屬於這一類。

    出現於：01 §1.11 工具安裝與本課程工具02 §2.10 EDA 工具地圖的四種切法

  • 程式庫library

    可重複使用的模組集合；投影片以「一個程式庫是一片森林、每個模組是一棵樹」比喻檔案與階層的關係。

    出現於：01 §1.12 Verilog 檔案與模組的外觀03 §3.11 RTL 由程式庫合成

  • 標準單元standard cell

    製程廠提供的固定高度、已繞好內部的基本元件（閘、正反器）；合成與佈局繞線都以它為單位。

    出現於：02 §2.7 由下而上合成八步03 §3.11 RTL 由程式庫合成
